# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

Play against the computer, choose your move, and see who wins!

## 🚀 Features

* Play Rock, Paper, Scissors against the computer.
* Computer generates a random choice for each round.
* Displays the winner of each round.
* Tracks user and computer scores.
* Detects draw situations.
* Interactive and simple user interface.

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## 🎯 How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will randomly select its move.
4. The winner of the round will be displayed.
5. Scores will update automatically.

## 📌 Game Rules

* Rock beats Scissors.
* Scissors beats Paper.
* Paper beats Rock.
* If both players choose the same move, the round is a draw.
